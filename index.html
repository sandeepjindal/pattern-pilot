Strategy with Command support

Why this fits

Your goal asks for interchangeable behavior, isolated tests, and runtime selection. Strategy keeps channel logic swappable while Command can encapsulate scheduled or retried sends.

Watch for

Avoid creating one class per tiny variation. Keep shared retry, tracing, and validation outside individual strategies unless the channel truly owns that policy.

Next action

  3. Wrap scheduled sends as commands with retry metadata.
